## 상태 정의
- `PARTIAL`: 고객사 화면 검토를 위한 정적/가상 화면. 실제 업무 처리 기능이 완료되었다는 뜻이 아님.
- `HOLD`: 정책/Formula/보안/Golden 증거가 미확정. 클릭 시 정책 확인 안내.
- `UNKNOWN`: 인계자료에서 충분한 기준을 확인하지 못함. 클릭 시 기준 확인 안내.
- `READY`: 현재 패키지에는 READY로 분류한 실제 업무 메뉴가 없음.

## 테스트 사실
- 소스 구조 및 파일 생성 여부 확인은 수행함.
- npm 의존성 설치, Vite 빌드, 브라우저 E2E, U.STRA API/DB 통합 테스트는 이 실행 환경에서 수행/입증되지 않았음. 따라서 빌드 PASS 또는 서버 배포 가능을 선언하지 않음.
